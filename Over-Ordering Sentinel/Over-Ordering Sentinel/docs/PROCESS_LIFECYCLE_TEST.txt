Hướng dẫn kiểm tra lifecycle của admin/backend/cloudflared

1. Mở `START_ONLINE.bat`.
2. Trong admin (mở tại http://127.0.0.1:8502), tạo public share link.
3. Mở CMD mới tại thư mục project (thư mục gốc nơi chứa `app.py`).
4. Chạy lệnh:

   python scripts/check_process_lifecycle.py
   hoặc
   py scripts/check_process_lifecycle.py

5. Ghi nhận trạng thái BEFORE (xem output):
   - cloudflared running: yes/no
   - backend 8501 listening: yes/no
   - admin 8502 listening: yes/no
   - danh sách process liên quan (chứa `app.py`, `online_admin_app.py`, `cloudflared`, hoặc đường dẫn project)

6. Bấm "Stop public share link" trong admin.
7. Chạy lại script kiểm tra (
   `python scripts/check_process_lifecycle.py` ) và so sánh.
8. Nếu `cloudflared running = no` thì Stop sharing hoạt động đúng.
9. Nếu `cloudflared running = yes` thì cần sửa `stop_tunnel` hoặc admin app.
10. Tạo public link lại nếu cần.
11. Đóng cửa sổ CMD `START_ONLINE.bat` (hoặc nhấn Ctrl+C trong cửa sổ đó).
12. Chạy lại script kiểm tra.
13. Kết quả mong muốn sau khi đóng CMD `START_ONLINE.bat`:
    - `cloudflared running = no`
    - `admin 8502 listening = no`
    - `backend 8501 listening = no` nếu backend do online launcher/admin khởi tạo (nếu backend do user khởi tạo riêng thì có thể vẫn chạy)

14. Nếu còn `cloudflared` hoặc port 8501/8502 vẫn mở thì cần sửa `launcher_online.py` cleanup logic.

Ghi chú:
- Không kill toàn bộ `python.exe` hoặc `cloudflared.exe` của hệ thống khi sửa.
- Kiểm tra PID/command line để chỉ dừng process do project khởi tạo.

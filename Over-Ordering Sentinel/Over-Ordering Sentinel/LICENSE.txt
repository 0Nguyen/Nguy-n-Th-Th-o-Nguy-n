Over-Ordering Sentinel
Copyright (c) 2026 Nguyen Thi Thao Nguyen

This project is created with the hope that data, public health, and technology can help protect patients, support fairer healthcare systems, and strengthen trust in universal health coverage.

The source code of Over-Ordering Sentinel is made available for everyone to use, study, share, improve, and build upon for public-interest, educational, research, healthcare review, and social-good purposes.

This project is especially intended to support students, public health workers, non-governmental organizations, medical review boards, audit teams, researchers, and healthcare oversight groups who want to examine unusual out-of-insurance ordering patterns among insured patients.
